  * **Tech Stack:** `Python`, `FastAPI`, `Streamlit`, `Pandas`, `SQLAlchemy`, `PostgreSQL`

* 🌍 **[SDG 8 Global Trade Pipeline](https://github.com/LaboNapitupulu/sdg8-global-trade-pipeline)**
